# 灵感熔炉 · 公众号数据同步插件

在你**日常使用的浏览器**里运行：真人登录态、真人访问，无自动化指纹。
**纯手动触发**：在灵感熔炉「运营总览」的公众号账号行点「从浏览器获取数据」，
网页会直接调用本插件，用你已登录的公众号后台会话抓一次「内容分析」数据并上报，
作为文章级表现分析的准实时数据源（替代 RedFox 的 T+1 延迟）。

## 工作原理

1. 灵感熔炉页面按钮 → `chrome.runtime.sendMessage` 调起插件（只接受与选项页配置的服务器同源的页面）；
2. 插件在**后台标签页**打开 `mp.weixin.qq.com`，页面脚本自动跳到「内容分析」页；
3. 按表头文字解析文章数据表（阅读/分享/在看/点赞/留言）；
4. POST 到 `POST /api/_/ingest/mp-stats`（`X-Ingest-Token` 鉴权）；
5. 服务端 upsert 进作品库并记录指标历史点，前端提示上报篇数并刷新；后台标签页自动关闭。

插件 ID 固定为 `kimpkibmhdimbomifeofhhefckgdhahj`（manifest 内置 key），前端按此 ID 调用。

## 安装

1. 服务端 `.env` 配置并重启：
   ```bash
   openssl rand -hex 16        # 生成令牌
   # 写入 .env：INGEST_TOKEN=上一步生成的值
   ```
2. Chrome 打开 `chrome://extensions/`，右上角开启「开发者模式」；
3. 点「加载已解压的扩展程序」，选择本目录（`extension/mp-stats/`）；
4. 点击扩展图标 →「选项」，填写：
   - 灵感熔炉地址（如 `http://localhost:8080`）
   - INGEST_TOKEN（与 .env 一致）
   - 公众号名称（**必须与灵感熔炉「我的账号」里的公众号同名**）
   - 点「测试连接」确认通过；
5. 在同一浏览器里登录公众号后台（`mp.weixin.qq.com`，扫码一次即可，会话由浏览器自己维持）；
6. 回到灵感熔炉「运营总览」，点公众号账号行的「从浏览器获取数据」验证。

## 常见问题

- **提示「触发页面（X）与选项页配置的服务器（Y）不一致」**：报错里会直接给出插件实际看到的来源 X 和你配置的 Y，核对哪个填错了。`localhost`/`127.0.0.1`/`::1` 同端口视为同源，可混用；但用局域网 IP/域名访问时，选项页地址必须和它同源（含端口）。
- **提示「未检测到插件」/无响应**：确认插件已启用；灵感熔炉页面刷新后再点。
- **图标显示 `ERR`**：扩展管理页 → Service Worker → 检查，看控制台日志；常见原因是未登录公众号后台、INGEST_TOKEN 不一致、公众号名与「我的账号」不同名。
- **图标显示 `0`**：内容分析页解析到 0 篇文章，可能是页面结构变了（见下节）。

## 页面结构变化怎么办

所有依赖 MP 后台页面结构的选择器都集中在 `content.js` 顶部的 `CONFIG` 常量里
（导航入口文字、分析页 URL 特征、表头关键字映射）。微信改后台页面时，
一般只需要调整这些文字/正则即可，解析逻辑（表头文字 → 列索引）本身对列顺序和 class 名不敏感。

## 安全说明

- INGEST_TOKEN 只存在本浏览器的 `chrome.storage.local`，只发往你配置的服务器地址；
- 插件不读取、不上传公众号后台的任何 Cookie / 会话凭证；
- 网页触发有同源校验：只有你配置的那个灵感熔炉地址能调起同步，其他网站调不动；
- 服务端 `INGEST_TOKEN` 泄露等于任何人都能写入作品数据，请像对待密码一样保管。
